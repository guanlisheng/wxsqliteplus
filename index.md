# A desktop workspace for SQLite

Browse database structure, inspect table data, and work with SQL in one focused
desktop application.

[Download the latest release](https://github.com/guanlisheng/wxsqliteplus/releases/latest) ·
[Explore the source](https://github.com/guanlisheng/wxsqliteplus)

**Free and open source · GPL-3.0 · Database files stay on your device**

## Explore your database

Move from finding an object to inspecting its schema, checking its data, or
writing a query.

- **Understand the structure:** Browse tables, views, indexes, triggers, columns,
  foreign keys, and DDL across open and attached databases.
- **Work with SQL:** Run statements and scripts, inspect query plans, and keep
  results and execution output close at hand.
- **Inspect and share data:** Filter and sort table data, inspect BLOB values,
  copy grid selections, and export results to UTF-8 CSV.
- **Find objects quickly:** Search tables, views, indexes, triggers, and columns
  across open databases.
- **Open encrypted SQLite files:** Use supported wxSQLite3 encryption codecs and
  enter the database key when prompted. Keys are not saved by the recent-files
  list.

## Designed to keep your data local

Open database files directly in the desktop app. No account or server-side
database import is required.

Compatible encrypted SQLite databases can be opened when their encryption
format matches an available codec. This includes MMEX `.mmb` and `.emb` files
when compatible. MMEX is one supported use case, not a separate product
requirement.
